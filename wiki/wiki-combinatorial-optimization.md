# 组合优化在EDA中的应用

RTL仿真器的多线程化本质上是一个组合优化问题：将电路模块分配到有限线程，在满足时序正确性约束的前提下，最小化通信开销与同步等待。而EDA领域对这类NP-hard问题已积累了丰富的求解工具——从精确求解的ILP/MIP到高效的元启发式，从群体智能到动态规划，从约束求解到近似算法。本章将这些工具按理论深度递进排列，给出可操作的建模范式与参数配置。

---

## 1. ILP / MIP：精确建模与求解器实践

### 1.1 核心求解方法

- **Branch and Bound**：通过变量分支与基于问题特定边界的搜索裁剪，有效剪枝解空间
- **Cutting Plane Method**：在线性规划松弛中添加有效不等式（Cuts），收紧边界，逼近整数解
- **Presolve / Preprocessing**：通过变量固定、约束传播、域缩减等手段，在求解前大幅简化问题规模

### 1.2 CP-SAT：OR-Tools的LCG架构

Google OR-Tools 的 CP-SAT 是一种 **Portfolio Solver**，核心特征：

- **Lazy Clause Generation (LCG)**：将问题增量式转换为 SAT 公式，利用 CDCL SAT 求解器进行搜索
- **动态线性松弛**：通过 Dual Simplex 在每个搜索节点执行少量迭代，利用增量性加速
- **Large Neighborhood Search (LNS)**：一旦发现可行解，启动不完整子求解器，通过 RINS 等局部搜索策略迭代改进
- **并行多策略**：多个完整子求解器在不同线程上并行运行，各自采用独特策略

| 特性 | CP-SAT (OR-Tools) | Gurobi / CPLEX (MIP) |
|------|-------------------|----------------------|
| 核心引擎 | CDCL SAT + CP + LCG | Branch and Cut + Barrier |
| 连续变量 | 不支持 | 完全支持 |
| 复杂逻辑约束 | 极强优势 | 需 Big-M 编码 |
| 经典纯 ILP | 接近商业级 | 行业标杆 |
| 调度问题 | 中小规模优于商业求解器 | 大规模实例缺少启发式 |
| 内部点法 | 无（仅 Simplex） | 支持 Barrier 算法 |

### 1.3 RTL分区/调度的ILP建模范式

```
Variables: X₀, X₁, X₂  ...（任务开始时间 / 分区归属）
Constraints:
  X₀ > 0; X₁ > 0; X₂ > 0;
  X₂ - X₀ ≥ 1;   -- 依赖约束：T₂ 在 T₀ 完成后至少 1 个时隙启动
  X₁ - X₀ ≥ 1;   -- 依赖约束
  X₂ - X₁ ≥ 1;   -- 依赖约束
Objective: Minimize X₂  -- 最小化总完成时间（makespan）
```

该范式可直接迁移到 **RTL 多线程仿真器的线程分配/调度**：
- 将模块/进程作为任务
- 数据依赖作为时序约束
- 目标函数最小化仿真周期或通信开销

### 1.4 变量/约束/目标函数设计

**RTL分区ILP模型示例**：

| 组件 | 设计 | 说明 |
|------|------|------|
| 二元变量 | `x_{i,k} ∈ {0,1}` | 模块 i 是否分配到线程 k |
| 负载约束 | `Σ_i w_i · x_{i,k} ≤ (1+ε)·W/K` | 线程 k 的负载不超过平均的 (1+ε) 倍 |
| 通信约束 | `y_{i,j} = 1` 若 i,j 跨线程 | `y_{i,j} = 1 - Σ_k x_{i,k}·x_{j,k}` |
| 目标函数 | `Minimize Σ_{(i,j)∈E} c_{i,j}·y_{i,j}` | 最小化跨线程通信代价 |

## 2. 元启发式：SA与GA的参数与性能

### 2.1 模拟退火（SA）

**核心机制**：温度控制的概率接受准则——温度高时接受劣化解概率大，温度低时趋向局部精细搜索

**SA参数典型配置**（VLSI Floorplanning 文献汇总）：

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 初始温度 | 使约80%劣解被接受的温度 | 经验设定 |
| 冷却率 | **0.95 ~ 0.999**（几何冷却） | 核心参数，过快易陷入局部最优 |
| 终止温度 | 接近0或达到最大迭代次数 | 通常10⁻⁶量级 |
| 马尔可夫链长度 | 100~1000次扰动/温度层 | 与问题规模成正比 |

**扰动方式**：随机交换一对模块 / 随机旋转一个模块 90°
**代价函数**：`Cost = α·(A/A_norm) + β·(Q/Q_norm)`，其中 A 为面积，Q 为线长，α+β=1

### 2.2 遗传算法（GA）

**GA典型参数配置**（VLSI Floorplanning 文献汇总）：

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 种群规模 | **50 ~ 200** | 取决于模块数 |
| 选择算子 | Tournament Selection（k=3~5） | 锦标赛选择 |
| 交叉率 | **0.8** | Modified One-Point Ordered Crossover |
| 变异率 | **0.01** | Swap Mutation / Rotation Mutation |
| 精英保留 | 5%~10% | 每代最优个体直接进入下一代 |
| 终止条件 | 500~2000代 | 或连续50代无改进 |

**MCNC基准实验数据**（Prabu et al., 2026）：

| 算法 | 线长缩减 (%) | 面积利用率 (%) | 运行时间 (归一化) |
|------|-------------|---------------|-----------------|
| SA   | 10.2        | 86.5          | 1.0             |
| DMT  | 12.8        | 88.1          | 0.8             |
| PSO  | 13.5        | 89.0          | 1.1             |
| **GA** | **15.0**  | **91.2**      | **0.7**         |

### 2.3 混合策略（Memetic Algorithm）

- **Memetic Algorithm (MA)**：在 GA 框架中嵌入局部搜索（如模块交换、压缩），在面积与线长优化上表现更优
- **混合 SA (HSA)**：B-tree + HSA，结合局部搜索与 SA 的全局探索能力
- **自适应 GA**：根据种群多样性动态调整交叉/变异概率
- **并行 GA**：同时优化物理约束（线长、过孔数）与串扰

## 3. 群体智能：PSO、ACO与禁忌搜索

### 3.1 粒子群优化（PSO）

**速度更新公式**：
```
v_ij(t+1) = w·v_ij(t) + c₁·r₁·(pbest_ij(t) - x_ij(t)) + c₂·r₂·(G_j(t) - x_ij(t))
x_ij(t+1) = x_ij(t) + v_ij(t+1)
```

| 参数 | 典型值 | 物理意义 |
|------|--------|----------|
| `w`（惯性权重） | **0.9 → 0.4** 线性递减 | 平衡全局探索与局部开发 |
| `c₁`（认知因子） | **2.0** | 向个体历史最优学习 |
| `c₂`（社会因子） | **2.0** | 向群体全局最优学习 |
| `r₁, r₂` | U(0,1) | 随机扰动，增强多样性 |
| 种群规模 N | 20~100 | 并行搜索粒度 |
| 最大迭代 T | 100~1000 | 终止条件 |

**收敛因子 PSO (CF-PSO)**：Clerc 提出用收缩因子 λ 替代惯性权重，理论上保证收敛：
```
λ = 2 / |2 - φ - √(φ² - 4φ)|,  φ = c₁ + c₂
```

### 3.2 蚁群优化（ACO）

**状态转移概率**（从 i 到 j）：
```
p_ijk(t) = [τ_ij(t)]^α · [η_ij]^β / Σ_s [τ_is(t)]^α · [η_is]^β
```

**信息素更新（全局）**：
```
τ_ij(t+1) = (1-ρ)·τ_ij(t) + ρ·Δτ_ij
Δτ_ij = Q / L_best   if (i,j) 属于全局最优路径
         0            otherwise
```

| 参数 | 典型值 | 说明 |
|------|--------|------|
| α（信息素重要性） | **1.0~4.0（常用 2.0）** | 大 α 加速收敛，但易早熟 |
| β（启发信息重要性） | **3.0~5.0（常用 4.0）** | 大 β 增强贪婪性 |
| ρ（全局蒸发系数） | **0.1~0.5（常用 0.1）** | 防止信息素过度积累 |
| ξ（局部蒸发系数） | 0.05~0.2（常用 0.1） | 增加多样性 |
| Q（信息素强度常数） | 100~1000（常用 100） | 缩放优质路径的奖励 |
| m（蚂蚁数量） | 0.5n ~ 1.0n | 并行搜索强度 |

**改进变体**：Ant Colony System (ACS)、MAX-MIN Ant System (MMAS)、ACO-GA混合、ACO-SA混合

### 3.3 禁忌搜索（Tabu Search）

**核心机制**：
- **禁忌表 (Tabu List)**：记录最近访问过的解/移动，禁止短期内重复，防止循环搜索
- **藐视准则 (Aspiration Criterion)**：若禁忌移动产生优于当前最优解的结果，则破例接受
- **邻域结构**：定义解的邻域（如模块交换、插入、旋转），在邻域内搜索最优非禁忌移动

**TBHPSO（Tabu + Hierarchical PSO）**：
- 在 PSO 每代迭代中，对层级结构顶层粒子应用 **Robust Tabu Local Search**
- 引入 ACO 式的启发式偏置项修正 PSO 速度更新方程
- 实验表明显著优于 QAP 领域经典算法 DivTS

### 3.4 群体智能算法对比

| 算法 | VLSI EDA 应用域 | 典型优势 | 典型局限 |
|------|----------------|----------|----------|
| **Tabu Search** | 模块分配、通道布线、QAP布局 | 避免循环、精细局部搜索 | 对初始解敏感，参数调参复杂 |
| **ACO** | 电路布线、路径规划、调度序列 | 组合优化强项，正反馈高效 | 收敛慢，参数敏感，信息素停滞 |
| **PSO** | 连续参数优化、3D Floorplanning | 实现简单，收敛快 | 标准版易早熟，离散空间需改造 |
| **PSO-SA 混合** | Placement、时序优化 | 兼顾全局探索与局部逃离 | 参数成倍增加 |
| **PSO-GA 混合** | 多目标 Floorplanning | 维持种群多样性 | 计算开销大 |

## 4. 动态规划：树覆盖与背包调度

### 4.1 FPGA技术映射中的树覆盖DP

**问题定义**：给定布尔网络，将其映射为 K-LUT 的集合，使面积或延迟最小化

**经典递推式**（DAGON / Chortle-crf）：
```
cost(v) = min_{pattern p matches at v} { cost(p) + sum(cost(child_i)) }
```

- **DAG-Map（Chen & Cong）**：不将网络分解为树，直接在 DAG 上进行标记。`h(v)` 为最小逻辑深度，若 `input(N_p(v) ∪ {v}) ≤ K`，则 `h(v) = p + 1`
- **时间复杂度**：树覆盖 DP 与树的大小成线性关系，即 **O(|V| + |E|)**

### 4.2 路径平衡技术映射

**Pasandi 等人工作**：将路径平衡代价纳入技术映射的 cost function，DP 在每个节点的最优匹配选择中同时考虑门面积和所需的平衡单元数量

- **最优性保证**：对于树结构（最多 2 输入门），该算法可证明给出最优解
- **与RTL仿真关联**：路径平衡概念类似于 RTL 多线程仿真中的同步屏障插入——在并行仿真中，需要通过同步屏障来平衡不同线程的执行进度

### 4.3 GAMA联合映射：线性时间映射-布局

**GAMA / FAST 工具**：
- 将数据流图（DFG）中的模块映射问题建模为**树覆盖**问题，同时在线性时间内完成模块布局
- **联合优化**：将映射（mapping）与布局（floorplanning）整合为一个 DP 过程，考虑总延迟包括 CLB 延迟和布线延迟
- **线性时间**：由于数据通路通常具有树状结构，DP 可在 **O(N)** 时间内完成

### 4.4 DyTAg背包调度

**DyTAg 算法**：将异构计算系统（HCS）中的任务调度问题建模为**0/1 背包问题**的动态规划解法

- **目标**：最小化 makespan（所有处理器上的最大完成时间）
- **DP 状态**：`dp[t][load]` 表示处理前 t 个任务时，各处理器的负载分配达到 `load` 状态的最小 makespan
- **RTL 仿真关联**：将仿真任务（如模块求值）分配到不同线程/核心，以最小化单周期仿真时间

### 4.5 稀疏动态规划的并行化（SKPDP）

**Sifat 的稀疏 DP 并行化**：
- **流水线并行**：P 个线程每次处理 P 行，线程 `Pk` 是 `Pk+1` 的生产者和 `Pk-1` 的消费者
- **同步机制**：每个线程维护输入/输出缓冲区，使用两个 OpenMP 锁确保生产者-消费者同步
- **空间复杂度**：`O(2NC + W_max · P)`
- **无死锁保证**：尽管线程数可能达到 O(N)，但等待相邻线程时会释放物理核心，不存在循环依赖

## 5. 约束求解：SAT / SMT与ML增强

### 5.1 SMT约束分解求解RTL

**赵燕妮等人（清华大学，2010）**：基于**超图划分**的约束分解方法

1. 将RTL电路的结构约束建模为**超图**（hypergraph），每个节点/边赋予适当权重
2. 利用**超图划分**（如 hMETIS）寻找带有最小割集的等量划分
3. 将原约束集分解为多个子约束集，每个子集对应一个子电路
4. 使用 SMT 求解器（Z3、Yices）分别求解各子问题，通过割集变量传递约束

**核心优势**：显著减小单次 SMT 求解的问题规模和搜索空间，实现分级验证

### 5.2 增量SAT与NAR优化

**Yao 等人（IEEE TCAD）**：NAR（Node Addition and Removal）技术
- 通过 ATPG 识别电路中的冗余节点，用更简单的节点替换复杂节点
- 仅使用 resyn2 逻辑优化：总验证时间约 25 小时
- NAR + resyn2 联合优化：总验证时间约 **14 小时**（节省约 39 小时中的大部分）

**Amazon Science（2025）**：增量式 SAT 应用于量子电路映射优化
- 增量求解：每次迭代不重编码整个问题，求解器复用内部状态
- 实验结果：比现有求解器方法快 **26 倍**

### 5.3 GNN/RL增强SAT（GLSVLSI 2025）

**GLSVLSI 2025** 论文提出用加权文字关联图（WLIG）和 GNN 增强 CDCL SAT 求解器：
- 离线初始化阶段，用 GNN 预测 SAT 实例的**主干变量**和 UNSAT 实例的**UNSAT 核心变量**
- 在开放 SAT 竞赛数据集上，比基线求解器多解决 **5%-7%** 的实例

**Gu 等人（arXiv 2025）**：RL 驱动的逻辑综合配方探索
- 将逻辑综合建模为 MDP，状态为当前网表特征，动作为选择 LS 操作
- 使用深度 Q 学习（DQN）训练 RL Agent，目标是最小化给定实例的 SAT 求解时间
- 带 RL 的 Agent 比随机策略节省 **11.95%** 的求解时间；定制化 mapper 比传统 mapper 快 **50.80%**

### 5.4 BIST测试模式生成

**Flores（INESC-ID PhD Thesis）**：基于 SAT 求解器的 BIST 测试模式生成
- 基于不确定变量赋值（don't cares）生成测试模式
- 建立完整优化模型强制兼容类（compatibility classes）合并
- 应用领域：片上自测试，实现封装后/系统内测试（on-line testing）

## 6. 近似/在线算法：理论保证与工程实践

### 6.1 Graham贪心调度

**问题定义**：给定 n 个作业，处理时间为 p_k，在 m 台相同机器上调度，最小化 makespan

**Graham 在线贪心算法**：
- **规则**：按任意顺序处理每个作业，将其分配到当前负载最小的机器上
- **近似比**：**2 - 1/m**
- **时间复杂度**：`O(n log m)`（使用优先队列）

### 6.2 LPT（Longest Processing Time first）

- **规则**：先将作业按处理时间降序排序，再贪心分配到最小负载机器
- **近似比**：**4/3 - 1/(3m)** — 贪心算法中已知最好的近似比之一
- **时间复杂度**：`O(n log n)`（主要由排序决定）
- **PTAS 扩展**：结合穷举法，先最优调度最大的 k 个作业，再贪心调度剩余，可得到任意精度 `(1+ε)` 的近似

### 6.3 在线竞争比

| 问题设定 | 算法 | 竞争比 | 备注 |
|----------|------|--------|------|
| 在线Makespan（不同释放时间） | 列表调度 | **2** | 信息在释放时可知 |
| 在线Makespan（逐个呈现） | Johannes 算法 | **1/2** | 信息逐步到达 |
| 刚性任务DAG在线调度 | Perotin 算法 | **O(log n)** | 渐进匹配离线近似比 |
| 货架算法（Shelf-based） | Next-Fit | **7.46** | 连续处理器约束 |
| 货架算法（Shelf-based） | First-Fit | **6.99** | 连续处理器约束 |

**关键理论**：对确定性在线算法，竞争比下界为 **Ω(log n)**。这意味着在事件到达顺序不可预测的 RTL 仿真中，任何在线调度算法都存在固有的性能上限。

### 6.4 VLSI全局布线的IP近似

**Deza 等人**：基于整数规划的全局布线多项式时间近似算法
- 确保所有布线需求同时满足，总代价被近似最小化
- 提供串行和并行两种实现，配合启发式策略提升解质量
- 在标准 benchmark 上表现优异，与最优整数规划模型相比具有竞争力

## 7. 对多线程RTL仿真器的启示

### 7.1 核心映射

| 组合优化方法 | 直接映射到RTL仿真器 | 适用场景 |
|-------------|-------------------|---------|
| ILP/MIP | 编译期模块分区精确建模 | 中小规模设计（<10K模块） |
| 元启发式（SA/GA） | 离线分区优化、探索性搜索 | 大规模设计、多目标优化 |
| 群体智能（PSO/ACO） | 连续参数调优、调度序列优化 | 运行时参数自适应、事件排序 |
| 动态规划 | 编译期调度预计算、事件表并行处理 | 树状结构数据通路、稀疏事件表 |
| 约束求解（SAT/SMT） | 调度可行性判定、死锁检测 | 形式验证保证调度正确性 |
| 近似/在线算法 | 运行时调度、事件驱动work stealing | 大规模在线调度、负载均衡 |

### 7.2 可操作的建议

1. **混合策略（SA + ILP）**：对大规模RTL设计（数百万门），先用启发式（Metis等）粗分，再对关键子区域用 CP-SAT 精调。coarse-grained heuristic + fine-grained ILP 是现代EDA工具的通行做法

2. **动态调度用在线算法**：全周期RTL仿真器（如Verilator、ARC）采用**离线调度**（编译期静态任务划分），可利用完整任务图信息；事件驱动仿真器必须在**在线**环境下处理事件，适合工作窃取或贪心列表调度。LPT排序启发式可将近似比从 `2-1/m` 改进到 `4/3-1/(3m)`

3. **约束求解用Portfolio Solver**：CP-SAT 作为 Portfolio Solver 在调度问题上已超越商业 MIP 求解器。对于RTL多线程仿真中的事件调度、CDC同步点排序，可建模为 `cumulative` / `no_overlap` 约束

4. **DP用于子问题分解**：RTL仿真中的多线程任务调度可借鉴 DyTAg 的背包 DP 模型——将宏任务（macro task）分配到线程，以最小化关键路径延迟。GAMA 的线性时间 DP 映射-布局联合算法启示我们：RTL仿真图的编译期优化也可使用 DP 在线性时间内完成

5. **SAT/SMT用于形式保证**：将RTL多线程仿真调度器建模为 SMT 约束系统，可形式化证明：在任意输入下，各线程的求值顺序满足 Verilog 语义的事件调度规则（IEEE 1364-2005 的 delta-cycle 和 time-slot 语义）

6. **近似算法的理论边界指导期望**：在线调度的竞争比下界（Ω(log n)）告诉我们，在事件到达顺序不可预测的RTL仿真中，任何在线调度算法都存在固有的性能上限。这解释了为什么事件驱动仿真器的并行度通常低于全周期仿真器
